# 产品视频精剪与重命名 Skill

当前使用版本：**V2.1**。批量去除产品视频多余片头、片尾，有效内容前后各预留最多 0.5 秒，统一命名并整理输出，源视频保留原位。

## 文件结构

- `视频修剪与重命名/V2.1/SKILL.md`：当前版本的完整执行规则。
- `视频修剪与重命名/V2/`：历史版本。
- `README.md`：使用说明。

## 输出目录

成品目录建在输入目录同级，命名为 `输入文件夹名称_剪辑后`；已存在则沿用。

例如输入 `D:\素材\TK\还没上传`，输出到 `D:\素材\TK\还没上传_剪辑后`。只处理输入目录直属视频，不递归处理子目录。

## 视频命名规则

公式：`开头/结尾_片段内容_景别_运镜_氛围_日期简写.mp4`

“开头/结尾”为可选前缀，二选一，实际文件名不包含斜杠：

- 带有打开包装或开箱的视频，通常填写 `开头`。
- 最后有引导手势（如指向购买入口、提示点击或下单）的视频，通常填写 `结尾`。
- 其余视频省略前缀及其后的下划线，直接从片段内容开始。
- 同时符合两类时，以主要用途判断；无法确定时省略前缀并标记复核。
- 开箱和引导手势属于有效内容，不应作为无效片头片尾删除。

示例：

- `开头_打开包装_近景_固定镜头_日常_261020.mp4`
- `开头_节日礼盒开箱_全景_环绕_圣诞_261020.mp4`
- `结尾_引导点击_中景_固定镜头_日常_261020.mp4`
- `外观展示_近景_固定镜头_日常_261020.mp4`

字段说明：

- **片段内容**：按成品实际保留的主要动作或展示内容命名。
- **景别**：特写、近景、中景、全景、多景别等。
- **运镜**：固定镜头、推进、拉远、横移、摇镜、环绕、跟拍等，判断摄像机运动。
- **氛围**：默认“日常”；明显节日场景使用具体节日名。
- **日期简写**：`YYMMDD`，优先使用素材拍摄日期，从源文件修改时间或媒体元数据获取；无法获取时使用处理当天日期。

默认不加序号；重名时追加 `_v2` 等标记，禁止覆盖。扩展名与实际容器一致，MOV 输出使用 `.mov`，公式中的 `.mp4` 仅为示例。

## 使用方法

让具备本地文件访问能力的 AI 读取 `视频修剪与重命名/V2.1/SKILL.md` 并执行。若需安装为技能，按所用 AI 工具的技能目录要求加载该版本。

示例指令：

> 请读取“视频修剪与重命名/V2.1/SKILL.md”，处理 D:\素材\TK\还没上传，按规则精剪、命名并整理输出。

## 运行条件

- AI 能访问素材目录、查看视频或抽帧图像；涉及说话内容时还需检查音频。
- 环境中可调用 FFmpeg、ffprobe 和 Python。
- 本仓库提供执行规范，FFmpeg 负责裁剪，AI 负责判断边界及命名；上传 GitHub 不会自动安装工具或授予本地磁盘访问权限。

## 输出与保护

- 每条视频独立处理，只修剪片头片尾，不删除中间内容、不拼接、不添加效果。
- 默认保留源容器与编码族，以及分辨率、方向、比例和实际帧率；HDR 按 SKILL 规则处理并核对色彩参数。
- 默认保留标准 AAC 音轨，移除苹果 APAC 空间音频和 mebx 数据流，以适配剪映；其他音轨按 SKILL 规则处理。
- 无需剪辑且可直接使用的视频直接复制，避免重复压缩。
- 源视频不覆盖、不删除、不移动、不改名；成品验证通过后才转为正式文件，支持任务记录恢复。
- 全部视频成功且验证通过后，默认将输入目录直属普通非视频文件移到成品目录；已有子目录等不参与移动。
- 输出带 BOM 的 UTF-8 `处理清单.csv`，记录源文件对应关系、裁剪时间、验证结果和待复核事项；完成报告列出每条成品时长。
