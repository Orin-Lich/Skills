# 产品视频精剪与重命名 Skill

批量去除产品视频多余片头、片尾，前后各预留0.5秒，统一命名并整理输出。源视频保留原位。

## 文件结构

- `trim-and-name-product-videos/SKILL.md`：AI读取的完整执行规则。
- `README.md`：本使用说明。

## 新版命名规则

输出文件夹：`精剪和重命名输出_无品牌产品名称_YYYY-MM-DD`

例如：`精剪和重命名输出_电弧打火机_2026-10-16`、`精剪和重命名输出_磁吸灯_2026-10-16`。

日期为任务开始当天用户当地日期，默认北京时间；以上日期仅为示例。同批次跨日恢复沿用原目录。混合产品按类别分别输出，同批次序号全局唯一。

视频文件名：`三位序号_主要动作或展示内容_景别_运镜.mp4`

例如：`001_点火演示_特写_固定镜头.mp4`、`002_外观展示_近景_环绕.mp4`。

文件名不包含主体产品名称、品牌或型号；产品类别只出现在输出目录和处理记录中。

## 使用方法

将完整的 `trim-and-name-product-videos` 文件夹放到使用中的AI工具所支持的技能目录；具体加载方式以该工具为准。也可直接让具备本地文件访问能力的AI读取SKILL.md并执行。

示例指令：

> 请使用 trim-and-name-product-videos 技能，处理 D:\素材\TK\2026-10-09\还没上传。产品类别为电弧打火机。按技能规则精剪、命名并整理输出。

产品类别可省略，由AI依据画面判断；不确定的内容会标记待复核。

## 运行条件

- AI能访问素材目录并查看视频或抽帧图像；涉及说话内容时还需检查音频。
- 环境中可调用FFmpeg、ffprobe和Python。
- 本仓库提供执行规范，不附带自动理解视频的模型或一键剪辑程序。FFmpeg负责裁剪，AI负责判断边界及命名。
- 上传GitHub不会自动安装工具，也不会让云端AI获得电脑D盘权限。

## 输出与保护

- 普通SDR优先MP4/H.264，保持分辨率和帧率，重新编码目标约18 Mbps（通常15–20 Mbps）。
- 无需剪辑且可直接使用的视频直接复制，避免重复压缩。
- 保留源视频；先验证再转为正式成品；支持通过任务记录恢复。
- 输出处理清单，记录源文件对应关系、裁剪时间和待复核事项。
- 全部成功后整理其他非视频文件；混合产品中无法确定归属的资料保留原位。
